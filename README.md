# แดชบอร์ดประวัติซ่อมบำรุงรายทะเบียน (GitHub Pages + Google Sheet)

หน้าเว็บอยู่บน GitHub Pages แต่ **ข้อมูลถูกเข้ารหัส** (data.enc) ถอดรหัสในเบราว์เซอร์ด้วยชื่อผู้ใช้+รหัสผ่านเท่านั้น
GitHub Actions ดึง Google Sheet ใหม่ทุก 15 นาที (หรือกดรันเองที่แท็บ Actions)

## ตั้งค่าครั้งเดียว
1. สร้าง repo ใน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมด (รวมโฟลเดอร์ .github)
2. Google Cloud Console: สร้างโปรเจกต์ → เปิด **Google Sheets API** → สร้าง **Service Account** → สร้างคีย์แบบ JSON
3. เปิด Google Sheet → แชร์ให้อีเมลของ Service Account (สิทธิ์ผู้ดู / Viewer พอ)
4. GitHub → Settings → Secrets and variables → Actions
   - Secrets: `GCP_SA_JSON` (เนื้อไฟล์ JSON ทั้งก้อน), `SHEET_ID` (ส่วนระหว่าง /d/ และ /edit ในลิงก์ Sheet), `APP_USER`, `APP_PASS`
   - Variables: `SHEET_TAB` (ชื่อแท็บที่เก็บข้อมูล)
5. GitHub → Settings → Pages → Source: **GitHub Actions**
6. แท็บ Actions → update-dashboard → Run workflow แล้วเปิดลิงก์ที่ได้

## ข้อกำหนดของ Sheet
- ระบบจับคู่คอลัมน์จาก **ชื่อหัวตาราง** (เหมือนไฟล์ Excel เดิม เช่น ทะเบียนรถ, วันที่รับบริการ, เลขที่กิโลเมตร, กลุ่มสินค้า, ชื่อสินค้า, จำนวน, ยอดขายรวม VAT, เลขที่ยกเลิกบิล) ลำดับคอลัมน์ไม่ต้องตรง และถ้าไม่มีคอลัมน์ 'เลขที่ใบเสร็จ' จะใช้ ทะเบียน+วันที่+สาขา เป็นตัวระบุ 1 ครั้งที่เข้าซ่อมแทน (เดิม: (ทะเบียน, ยี่ห้อ, รุ่น, วันที่, ไมล์, สาขา, เลขใบเสร็จ, ... ยอดขายรวม VAT, ยกเลิกบิล ...) แถวแรกเป็นหัวตาราง
- **เติมข้อมูลใหม่ต่อท้ายแถวล่างสุด** ถ้าเลขใบเสร็จซ้ำกับของเดิม ระบบยึดชุดล่างสุด (แทนที่ทั้งบิล) ส่วนบิลที่ไม่ได้เติมซ้ำคงเดิม
- ต้องเติมบิลครบทุกบรรทัด และแถวของบิลเดียวกันต้องติดกัน

## ความปลอดภัย
- รหัสผ่านใช้เป็นกุญแจเข้ารหัสข้อมูล ถ้าตั้งสั้น/เป็นตัวเลขล้วน คนที่โหลด data.enc ไปลองเดาได้ **ควรใช้ 12 ตัวอักษรขึ้นไป**
- ห้ามใส่ชื่อผู้ใช้/รหัสผ่านลงในไฟล์ในโปรเจกต์ ใส่ใน Secrets เท่านั้น
- เปลี่ยนรหัส = แก้ Secret แล้วรันใหม่ (ทุกคนต้องล็อกอินใหม่)

## ทางเลือกที่ไม่ต้องใช้ Google Cloud Console: Apps Script
1. เปิด Google Sheet → ส่วนขยาย → Apps Script → วางโค้ดจาก `apps_script.gs` แล้วแก้ `TOKEN` และ `TAB`
2. Deploy → New deployment → ประเภท Web app → Execute as: **Me** → Who has access: **Anyone** → Deploy → อนุญาตสิทธิ์ (ถ้าขึ้น "unverified" กด Advanced → Go to ...) → คัดลอก Web app URL
3. GitHub Secrets: `APPS_SCRIPT_URL` (URL ข้างบน), `APPS_SCRIPT_TOKEN` (ค่าเดียวกับ TOKEN), `APP_USER`, `APP_PASS` (ไม่ต้องใช้ GCP_SA_JSON / SHEET_ID / SHEET_TAB)
4. ทำขั้น Pages และ Run workflow ตามเดิม
- ใครมี URL แต่ไม่มี TOKEN จะดึงข้อมูลไม่ได้ ถ้า TOKEN รั่วให้เปลี่ยนทั้งในสคริปต์และ Secret แล้ว Deploy ใหม่
- ถ้าชนโควตาของบัญชีฟรี ให้ลดความถี่ใน update.yml (เช่น เปลี่ยน `*/15` เป็น `0 * * * *` = ทุกชั่วโมง)

## ถ้า Sheet ไม่มีคอลัมน์ 'เลขที่ใบเสร็จ'
ระบบจะไม่ตัดแถวซ้ำให้ (เพื่อไม่ให้แถวจริงหาย) ถ้าเติมไฟล์ซ้ำยอดจะนับซ้ำ วิธีที่ดีที่สุดคือเพิ่มคอลัมน์ 'เลขที่ใบเสร็จ' ใน Sheet จะได้ใช้กฎ 'ยึดบิลใหม่' ได้เต็มรูปแบบ หรือตั้ง Variable `DEDUPE_NO_RECEIPT` = 1 เพื่อให้ตัดแถวที่เหมือนกันทุกช่องและถูกเติมซ้ำภายหลัง (ทดสอบกับข้อมูลชุดนี้พบว่าอาจตัดแถวจริงออกประมาณ 144 แถวจาก 33,708)
